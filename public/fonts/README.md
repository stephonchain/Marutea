# Fonts Marutea

Déposer ici les fichiers de fonts (licences requises) :

- `Playlist-Script.woff2` — titres / display
- `Okomito-Regular.woff2` — corps de texte
- `Okomito-Medium.woff2`
- `Okomito-Bold.woff2`

Les `@font-face` sont déclarés dans `app/globals.css`.
Fonts locales (pas de Google Fonts) pour les performances et le RGPD.
En attendant les fichiers, le site retombe sur `cursive` / `sans-serif`.
